# GameTime

Веб-сервис бронирования игрового клуба. Семестровый проект.

**Стек:** Django 5.2, PostgreSQL 17, Django Templates, Tailwind CSS 4, HTMX, Vanilla JS, Docker Compose.

## Требования

- Docker Desktop (с запущенным движком)
- Git

## Запуск

    git clone <адрес репозитория>
    cd GameTime
    copy .env.example .env

Открой `.env`, задай свои `DJANGO_SECRET_KEY` и `POSTGRES_PASSWORD`.
Ключ можно сгенерировать так:

    python -c "import secrets; print(secrets.token_urlsafe(50))"

Затем:

    docker compose up -d --build
    docker compose exec web python manage.py migrate
    docker compose exec web python manage.py createsuperuser
    docker compose exec web python manage.py seed_equipment
    docker compose exec web python manage.py seed_demo --password "<пароль демо-клиентов>"

Сайт: http://localhost:8000 · Django admin: http://localhost:8000/admin/

Роль «Администратор клуба» выдаётся в Django admin (Пользователи → роль). Суперпользователь, созданный командой выше, получает её автоматически.

## Сервисы

- `web` — Django (порт 8000)
- `db` — PostgreSQL
- `tailwind` — пересборка CSS из `static/src/input.css` в `static/css/styles.css`

После перезапуска компьютера выполни `docker compose up -d`, иначе контейнеры будут остановлены.

## Тесты

    docker compose exec web python manage.py test

Тесты используют тестовую базу PostgreSQL (нужна для проверки блокировок и ограничения на пересечение броней).

## Демо-данные

- `seed_equipment` — 2 зоны и 8 устройств. Повторный запуск обновляет их по названию (сбросит ручные правки этих записей).
- `seed_demo` — 3 вымышленных клиента (`demo.client1..3@example.com`) и до 15 броней с разными статусами. Повторный запуск пересоздаёт только брони демо-клиентов. Работает при `DJANGO_DEBUG=1`.
- Пароль демо-клиентов задаётся ключом `--password`, в репозитории его нет.

## Роли и доступ

| Роль | Возможности |
|---|---|
| Гость | главная, каталог, страница устройства, слоты, вход и регистрация |
| Клиент | + бронь, «Мои брони», отмена своей брони до начала, профиль, смена пароля |
| Администратор клуба | + панель клуба, начало и завершение сеансов, неявка, отчёты |

Роль нельзя выбрать при регистрации: все новые пользователи — клиенты.

## URL, методы и права

| URL | Метод | Кто | Что делает |
|---|---|---|---|
| `/` | GET | все | главная |
| `/equipment/` | GET | все | каталог: поиск `q`, фильтры `type`, `zone`, пагинация |
| `/equipment/<id>/` | GET | все | страница устройства и выбор времени |
| `/equipment/<id>/slots/?date=&duration=` | GET | все | слоты на дату (HTMX) |
| `/accounts/register/`, `/accounts/login/` | GET, POST | гость | регистрация, вход |
| `/accounts/logout/` | POST | вошедший | выход |
| `/accounts/profile/`, `/accounts/password/` | GET, POST | вошедший | профиль, смена пароля |
| `/bookings/create/` | POST | вошедший | создать бронь |
| `/bookings/mine/?status=` | GET | вошедший | свои брони |
| `/bookings/<id>/` | GET | владелец | детали (чужая бронь — 404) |
| `/bookings/<id>/cancel/` | POST | владелец | отмена до начала |
| `/club/?date=&status=&zone=` | GET | админ клуба | панель клуба |
| `/club/bookings/<id>/start/`, `/finish/`, `/no-show/` | POST | админ клуба | смена статуса |
| `/club/reports/?from=&to=` | GET | админ клуба | отчёт за период |

Ошибки: незалогиненный → редирект на вход, клиент в панели клуба → 403, чужая бронь или неизвестный объект → 404.

## Правила бронирования

- Рабочий день по умолчанию 10:00–23:00 в часовом поясе клуба, без перехода через полночь (настраивается в Django admin → Настройки клуба).
- Шаг 30 минут, минимум 30 минут, продолжительность в интерфейсе от 30 минут до 2 часов, не дальше 30 дней вперёд.
- Начало в будущем, оборудование и его зона активны.
- Интервалы полуоткрытые `[start, end)`: соседние брони не пересекаются.
- Цену считает сервер, тариф и сумма фиксируются в брони.
- Создание атомарно: блокировка строки устройства (`select_for_update`) внутри транзакции плюс ограничение PostgreSQL на пересечение. Есть тест на одновременные запросы.
- Статусы: `confirmed` → `in_progress` → `completed`; `confirmed` → `cancelled` (клиент, до начала); `confirmed` → `no_show` (администратор, после начала). Начать сеанс можно за 15 минут до начала и до конца брони.

## Известные ограничения

- Адрес, телефон и часы работы в блоке «Контакты» на главной — демо-значения.
- Оборудование, зоны, тарифы и часы работы меняются через Django admin (отдельных форм в панели клуба пока нет).
- Фото оборудования — пути к файлам в `static/images/`, загрузки через интерфейс нет.
- Нет восстановления пароля, входа через Google и онлайн-оплаты.
